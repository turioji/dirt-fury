# DIRT FURY

林道爆走モトクロス — モトクロスバイクで山あいの未舗装林道を走る3Dブラウザゲーム。

Three.js r128 / HTML1ファイル完結 / Vanilla JS。ブラウザで `index.html` を開くだけで遊べます。

## 遊び方

コースを3周するタイムアタック。ジャンプ台（赤い旗）で飛び、ウォッシュボード区間を抜け、木にぶつからないように走ります。

| キー | 操作 |
|---|---|
| W / ↑ | アクセル |
| S / ↓ | ブレーキ・バック |
| A D / ← → | ハンドル |
| Shift / SPACE | リアブレーキ・スライド |
| R | コースに復帰 |
| M | エンジン音 ON/OFF |
| SPACE / Enter | スタート・リトライ |

スマホでは画面下に操作ボタン（◀ ▶ / BRAKE / GAS）が出ます。横持ち推奨。

転倒できるのは3回まで（3回でゲームオーバー）。ギアは5速の自動シフトで、回転計を見ながら走れます。

## コース

| コース | 特徴 |
|---|---|
| 森の林道 | ジャンプ台とウォッシュボード |
| 廃坑トンネル | 暗いトンネル・ヘッドライト・トロッコ・落盤・光の差す縦穴 |
| 渓谷アドベンチャー | 吊橋・川渡り・大岩の門・岩の迷路・倒木・崖沿いの細道・大ジャンプ |
| 棚田と農道 | あぜ道・段々ジャンプ・ぬかるみ |
| 紅葉の林間コース | 赤い鉄橋・鉄道ジャンプ（列車が通る切り通しを飛び越える）・落ち葉 |
| 8の字サーキット | 立体交差で8の字に走る土のサーキット：S字・ヘアピン・スプーン・高速コーナー・シケイン・テーブルトップ・ウォッシュボード・キッカー、外側は砂利の安全地帯 |
| 火山のガレ場 | 溶岩ジャンプ・溶岩台地ドロップ・テーブルトップ・ダブルジャンプ・リズムセクション・岩の橋・ガレ場・噴石 |
| 恐竜ジャングル | ワニの川ジャンプ・丸太橋・ワニの沼（噛みつきをよける）・ティラノの追跡（後方の小窓つき）・遺跡の門・首長竜と翼竜 |
| モトクロス・グランプリ（レース） | ライバル3台と4周の対戦・スタートゲート・土手カーブ・テーブルトップ・ダブルジャンプ・リズムセクション・ウォッシュボード |
| フィヨルド・ダウンヒル | 一本道の山下り：つづら折り・ガレ場・岩棚・フィヨルドの断崖ジャンプ（タイムと飛距離） |

タイトル画面でコースを選択（1〜9・0キーでも切り替え可）。自己ベストはコースごとに記録されます。
