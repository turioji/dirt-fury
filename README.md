# DIRT FURY

林道爆走モトクロス — モトクロスバイクで山あいの未舗装林道を走る3Dブラウザゲーム。

Three.js r128 / HTML1ファイル完結 / Vanilla JS。ブラウザで `index.html` を開くだけで遊べます。

## 遊び方

コースを3周するタイムアタック。ジャンプ台（赤い旗）で飛び、ウォッシュボード区間を抜け、木にぶつからないように走ります。

| キー | 操作 |
|---|---|
| W / ↑ | アクセル |
| S / ↓ | ブレーキ・バック |
| A D / ← → | ハンドル |
| Shift / SPACE | リアブレーキ・スライド |
| R | コースに復帰 |
| M | エンジン音 ON/OFF |
| SPACE / Enter | スタート・リトライ |

スマホでは画面下に操作ボタン（◀ ▶ / BRAKE / GAS）が出ます。横持ち推奨。

転倒できるのは3回まで（3回でゲームオーバー）。ギアは5速の自動シフトで、回転計を見ながら走れます。

## コース

| コース | レベル | 特徴 |
|---|---|---|
| 森の林道 | 初級 | ジャンプ台とウォッシュボード |
| 廃坑トンネル | 中級 | 暗いトンネル・ヘッドライト・トロッコ・落盤・光の差す縦穴 |
| 渓谷アドベンチャー | 上級 | 吊橋・川渡り・大岩の門・岩の迷路・倒木・崖沿いの細道・大ジャンプ |
| フィヨルド・ダウンヒル | トライアル | 一本道の山下り：つづら折り・ガレ場・岩棚・フィヨルドの断崖ジャンプ（タイムと飛距離） |

タイトル画面でコースを選択（1〜4キーでも切り替え可）。自己ベストはコースごとに記録されます。
